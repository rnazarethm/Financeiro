Como obter
1
Crie o Google Sheet
Importe seu Excel no Google Drive → converta para Sheets. Nomeie a aba principal Gastos e crie mais duas: Config e Simulacoes.
2
Google Cloud Console
Ative a Sheets API → crie credencial OAuth 2.0 (Aplicativo da Web) → adicione a URL do GitHub Pages como origem autorizada.
3
Cole os IDs
O Client ID vem das credenciais OAuth. O Spreadsheet ID fica na URL do Sheet: spreadsheets/d/[ID]/edit
