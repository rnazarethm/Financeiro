Como obter essas informações
1
Crie o Google Sheet
Faça upload do seu Excel no Google Drive → clique com botão direito → Abrir com Google Planilhas. Renomeie a aba principal para Gastos. Crie mais duas abas: Config e Simulacoes.
2
Crie o projeto no Google Cloud
Acesse console.cloud.google.com → Novo projeto → Ative a API "Google Sheets API" → Vá em Credenciais → Criar credencial → ID do cliente OAuth 2.0 → Tipo: Aplicativo da Web. Adicione a URL do GitHub Pages em "Origens JavaScript autorizadas".
3
Copie os IDs
O Client ID aparece nas credenciais OAuth. O Spreadsheet ID está na URL do seu Sheet: docs.google.com/spreadsheets/d/[ID AQUI]/edit
